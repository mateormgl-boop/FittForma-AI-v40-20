# Surface: FittForma AI app shell (index.html)

Mode: Operate. Build path: code-led (app screen). Direction pinned by the owner's reference mockups (light + dark, six sections + FittAI); no concept roll was run.

## Direction contract

THESIS: One phone-first training app where every section has its own colour but the same component family; refuses the grey dashboard with one accent.
OWN-WORLD: Light default (#f3f6fb ground, white cards, soft shadows) and a deep navy dark theme (#070b18 ground, #0e1528 panels). Module colours: Inicio/plan blue-violet, Entrenar blue, Running teal, Nutrición green, Progreso violet, Comunidad magenta, Perfil indigo. Pill buttons with module gradient, outline secondary, pill tabs, rounded 18–22px cards, Inter-like sans, real gym photos under dark overlays, ring and line charts in module colour. Logo: F forming a running figure, blue→violet gradient.
STORY: The person sees today's state (week, habits, recent activity), logs a workout/meal/water/run in one or two taps, and sees progress and badges from real records only.
FIRST VIEWPORT: Sticky header (logo, theme toggle, Más), section title + subtitle, then a hero band in the module colour or photo hero with the primary action; bottom nav of six items on phone, left rail on desktop.
FORM: Operate working product; seed: none (direction pinned by owner references, roll not run).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
